# Матрицы комплексных чисел

Консольная программа на Java. Позволяет складывать, умножать и делить матрицы, транспонировать их и вычислять определитель. Результат операции становится текущей матрицей, с которой можно работать дальше.

Деление A / B выполняется как A * B⁻¹. Если матрица B необратима, программа выводит ошибку.

## Запуск

В папке проекта выполнить:

```text
javac --release 8 -encoding UTF-8 ComplexNumber.java Matrix.java Main.java
java Main
```

### Ввод

Размер вводится как `строки столбцы`, например `2 2`.

Каждый элемент вводится двумя числами: действительная и мнимая части. Например, `2 -3` означает `2-3i`.
